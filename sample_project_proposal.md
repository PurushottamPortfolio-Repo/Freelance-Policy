# PROJECT PROPOSAL & AGREEMENT

## Alltinium Website Development

**Client:** Alltinium Aerometrix Private Limited

**Developer:** Purushottam Kumar

**Project:** Corporate Website Development

**Reference:** https://alltinium.com/

**Total Project Value:** ₹25,000

**Estimated Duration:** 15 Working Days

---

## 1. Project Objective

Development of a responsive corporate website for Alltinium based on the approved reference website, including its agreed design, structure, content presentation, functionality, and responsive behaviour.


## 2. Scope of Work

The project includes the following **6 pages**:

1. Home
2. About
3. Materials
4. Manufacturing
5. Blogs
6. Contact

### Included Features

* Responsive design for mobile, tablet, and desktop
* Responsive navigation
* Contact/enquiry form
* Form validation
* Email notification for enquiries
* Blog/content section
* Materials/product presentation
* Services and industry sections
* CTA buttons and navigation
* Cross-browser compatibility
* Basic SEO implementation
* Basic performance optimization
* Production deployment


## 3. Project Deliverables

The developer will provide:

* Completed website within the agreed scope
* Responsive implementation
* Functional enquiry/contact system
* Production deployment
* Final project/source files after full payment
* Basic handover guidance


## 4. Timeline

**Total Development Time: 15 Working Days**

| Phase                     |            Duration |
| ------------------------- | ------------------: |
| Project Setup & Structure |              2 Days |
| UI Development            |              5 Days |
| Functionality & Forms     |              4 Days |
| Testing & Optimization    |              2 Days |
| Final Review & Deployment |              2 Days |
| **Total**                 | **15 Working Days** |

The timeline begins after receipt of the initial payment and required project materials.

Delays caused by pending client content, approvals, feedback, access, or third-party services will extend the delivery timeline accordingly.


## 5. Revisions

The project includes **2 revision rounds**.

A revision round means one consolidated list of reasonable changes related to the approved design and project scope.

Included revisions:

* Text/image changes
* Minor layout adjustments
* Minor spacing/colour changes
* Minor UI refinements

New pages, new features, major redesigns, or changes to approved functionality are outside the revision scope and will be quoted separately.
